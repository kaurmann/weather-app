# Weather App ☀️🌧️

A simple web app that shows real-time weather using the OpenWeatherMap API.

## Features

- Live weather data
- Temperature and condition display
- Clean responsive design
- City-based search
- Built with HTML, CSS, and JavaScript

## How to Use

1. Enter a city name (e.g., London)
2. Click "Get Weather"
3. View real-time temperature and condition
